What you learn

  • Write operator+= as a member function and operator+ as a free function that uses it, for a small Vector2 type.
  • Explain when an operator must be a member or a free function, and predict the error for 3 * v.
  • Write operator<< that prints a type and returns the stream, so that you can chain the output.
  • Write a default operator== and predict which comparisons compile with it in C++20.
  • Explain the difference between copy assignment and copy construction, and find the self-assignment bug in an operator=.

Question 1 of 43 L2 · Apply member-vs-free-operator In the video

Choose one: Vector2 has only a member operator* that takes an int. Which expression compiles?

Only v * 3. A member operator gets its left operand as *this. For 3 * v, the left operand is an int, so you need a free function (ex08, ex09).

Question 2 of 43 L2 · Apply equality-operator In the video

Choose one: Point declares only a default operator==. In C++20, which expressions compile?

a == b and a != b. C++20 rewrites a != b as !(a == b). An operator== does not give < or > (ex19, ex37).

Question 3 of 43 L2 · Apply copy-assignment In the video

Line 4. Lines 2 and 3 make new objects, so they call the copy constructor. Line 4 changes d, an object that exists (ex39).

Question 4 of 43 L1 · Recall operator-overloading

Choose one: Vector2 has a member function operator+. Which call does the compiler make for a + b?

For a member operator, the left operand is the object, so a + b calls a.operator+(b) (ex04). The call operator+(a, b) is the form for a free function.

Question 5 of 43 L1 · Recall operator-overloading

Choose all that apply: Which operators can you overload? Select all correct answers.

Select all that apply.

You can overload +=, [] and <<. You cannot overload ::, ., .* and ?: (cppreference: operator overloading, restrictions). You also cannot make a new operator, such as **.

Question 6 of 43 L2 · Apply operator-overloading

Predict the output: The function operator^ of Number calculates a power. What does this program print?

An overloaded operator keeps the precedence of the built-in operator.

two ^ (2 + 1) is 2 to the power 3, so a.value is 8. b.value + 1 is 4 + 1.

Question 7 of 43 L1 · Recall operator-overloading

True or false: You can write int operator+(int, int) to change the result of 2 + 2.

An operator overload needs at least one operand of a class type or an enumeration type. The compiler rejects int operator+(int, int) (ex05).

You cannot change an operator for the built-in types. You can only add operators for your own types.

Question 8 of 43 L1 · Recall operator-overloading

Fill the blank: For a free function, the compiler turns a + b into the call ____blank(a, b).

The name of the function is operator+. You can also write the call operator+(a, b), and it gives the same result as a + b (ex04).

Question 9 of 43 L2 · Apply operator-overloading

True or false: When you write operator+ for a type, the compiler also makes operator+= for that type.

The compiler does not make += from +. You write += and + as two functions.

The usual design writes += first, as a member. Then + is a free function that uses += (ex03). Only for comparisons, C++20 rewrites a != b as !(a == b).

Question 10 of 43 L1 · Recall member-vs-free-operator

Choose one: How many parameters does a member operator+ for two Vector2 objects have?

A member operator gets its left operand as *this. So a binary member operator has one parameter, the right operand (ex01). A free binary operator has two parameters.

Question 11 of 43 L1 · Recall member-vs-free-operator

Match the terms: Match each operator to the usual place for its function.

=, [], () and -> must be members (ex12). An operator that changes the object is usually a member. A symmetric operator and << are free functions or hidden friends (ex03, ex13).

Question 12 of 43 L3 · Analyze member-vs-free-operator

Line 6 declares a member, so *this is a third operand. GCC reports must have either zero or one argument. Write friend at the start of line 6. Then the function has two operands, and an int converts on both sides (ex10).

Question 13 of 43 L3 · Analyze member-vs-free-operator

Choose one: Money has a constructor Money(int). Why does 50 + price compile with a hidden friend operator+(Money, Money), but not with a member operator+(Money) const?

The compiler looks for a member only in the class of the left operand, and int has no members. So with a member, an int converts only on the right (ex11). A hidden friend gets both operands as parameters, so both can convert (ex10).

Question 14 of 43 L2 · Apply member-vs-free-operator

True or false: You can write operator[] as a free function, the same as operator+.

operator=, operator[], operator() and operator-> must be member functions (cppreference: operator overloading). GCC rejects a free operator[] with must be a member function.

Write operator[] in the class. Usually you write two forms: a non-const form and a const form (ex30).

Question 15 of 43 L1 · Recall stream-insertion

Take the value by const reference. Then the operator prints const objects and temporary objects, and it makes no copy (ex13).

Question 16 of 43 L2 · Apply stream-insertion

Question 17 of 43 L2 · Apply stream-insertion

Choose one: Which return type is correct for an operator<< that prints a Vector2?

Return the same stream by reference, so that std::cout << a << '\n' continues the chain (ex14). With void, the next << gets no stream. A return by value does not compile, because a stream has a deleted copy constructor (ex17).

Question 18 of 43 L2 · Apply stream-insertion

  1. The last << gets the stream again and prints b
  2. The next << gets that stream and prints and

The chain is a set of nested calls: operator<<(operator<<(operator<<(std::cout, a), " and "), b). The inner call occurs first, and each call returns the stream for the next call (ex14).

Question 20 of 43 L2 · Apply equality-operator

A default <=> gives <, <=, > and >=. It also declares a default operator==, which gives == and != (ex22). It gives no arithmetic operators.

Question 22 of 43 L3 · Analyze equality-operator

True or false: A default operator== compares the values that pointer members point to.

A default operator== compares each member with ==. For a pointer member, it compares the addresses (ex23).

Two Reading objects that point to two different int objects with the value 7 are not equal. Write your own operator==, or keep a value member instead of a pointer.

Question 25 of 43 L2 · Apply copy-assignment

Question 26 of 43 L2 · Apply copy-assignment

The implicit copy assignment assigns each member in declaration order and returns a reference to the left object (cppreference: copy assignment operator). That is why a = b = c works for Vector2 (ex25).

Question 28 of 43 L2 · Apply copy-assignment

True or false: a = b = c; first assigns c to b, and then assigns b to a.

= groups from right to left, and b = c returns a reference to b. Then a = b uses that reference (ex25).

Return *this by reference from operator=. Then the chain works the same as for int.

Question 29 of 43 L3 · Analyze copy-assignment

Choose all that apply: Buffer& operator=(Buffer other) uses copy-and-swap. Which statements are correct? Select all correct answers.

Select all that apply.

The parameter is a copy, so self-assignment swaps with a copy and is safe (ex27). After the swap, other holds the old data, and its destructor deletes it. For a named argument such as b, the copy constructor copies it into the parameter (ex27).

Question 30 of 43 L2 · Apply copy-assignment

Choose one: Account has a member const int id;. What occurs for a = b; with two Account objects?

A const member cannot change, so the compiler deletes the implicit copy assignment (ex28). The copy constructor still works: Account c = b; compiles.

Question 31 of 43 L4 · Senior copy-assignment

Choose all that apply: Which statements about copy-and-swap are correct? Select all correct answers.

Select all that apply.

The copy occurs before the swap, so an exception leaves *this as it was. This is the strong exception guarantee: on an exception, the object does not change (cppreference: operator overloading, assignment operator). The cost is a new copy for each assignment. Copy-and-swap needs a correct copy constructor (ex27).

Question 34 of 43 L3 · Analyze canonical-forms

Question 35 of 43 L3 · Analyze canonical-forms

Choose one: Why does the canonical free operator+ take its left operand by value?

operator+ must not change its operands. The parameter is the copy, so return left += right; changes only the copy (ex03). A const reference also binds to a temporary object, so the second choice is wrong.

Question 36 of 43 L3 · Analyze canonical-forms

True or false: An overloaded operator&& evaluates its right operand only when the left operand is true.

An overloaded && is a function call, so the program evaluates both operands before the call (ex34).

An overloaded && never short-circuits. From C++17, the program evaluates the left operand first, but it always evaluates the right operand too. Do not overload &&, || or the comma operator.

Question 38 of 43 L4 · Senior member-vs-free-operator

Choose one: Argument-dependent lookup (ADL) finds a function through the types of its arguments. Why do many teams write operator== and operator<< as hidden friends, not as free functions in the namespace?

Only argument-dependent lookup finds a friend that you define only in the class, when an argument has the class type (cppreference: friend declaration). It also reads private members (ex15). The inline and virtual choices are false.

Question 39 of 43 L4 · Senior equality-operator

A default operator== compares every member in declaration order (ex19). When equality has a different meaning, write your own operator== that compares id. It also costs less, because it compares one int.

Question 40 of 43 L3 · Analyze copy-assignment

Put in order: operator=(Buffer other) uses copy-and-swap. Put the steps of a = b; in order.

Drag the handle, or use the arrow buttons. With a row focused, press Alt + Up or Alt + Down.

  1. The copy constructor makes the parameter other from b
  2. The destructor of other deletes the old data of a
  3. The function returns *this
  4. std::swap exchanges the members of *this and other

The copy occurs before the function body. The swap gives a the new data and gives other the old data. After the return, the destructor of other deletes the old data (ex27).

Question 41 of 43 L1 · Recall canonical-forms

Match the terms: Match each operator to its canonical return type for a type T.

An operator that changes the object returns a reference to it. An operator that makes a new value returns it by value (ex35). operator<< returns the stream, and a comparison returns bool.

Question 42 of 43 L4 · Senior operator-overloading

Choose one: Is a call of an overloaded operator+ slower than a call of a named function add with the same body?

a + b is only another syntax for the call operator+(a, b) or a.operator+(b) (ex04). The compiler optimizes it the same as add(a, b). The parameter types, not the operator syntax, decide if a copy occurs.

Question 43 of 43 L4 · Senior stream-insertion

Choose one: A program writes millions of Vector2 values to a file. Which operator<< body costs the least?

Direct writes into out make no temporary string, so they need no extra memory allocation (ex13). The two other bodies make a temporary object for each value and then copy its characters again.
