C++ Constructors and Destructors

About 12 min 37 quiz questions 62 workbook questions
Start the quiz Open the workbook Compiler Explorer (opens in a new tab)

What you learn

  • Write a constructor that makes an object valid from the start, with a member initializer list for each member.
  • Predict the order in which members initialize, and find the bug when the member initializer list has a different order.
  • Explain when a destructor runs, and predict the reverse order in which the destructors run.
  • Name the default and copy constructors that the compiler writes, and tell when it does not write them.
  • Explain what the copy constructor copies, and find the bug in a shallow copy of a pointer member.

Question 1 of 37 L2 · Apply member-initializer-list In the video

Choose one: Meter has a reference member, total_. Which constructor compiles?

Only the constructor with the member initializer list. A reference must refer to an object from the start, so an assignment in the body is too late. The body version gives "uninitialized reference member" (GCC) and "must explicitly initialize the reference member" (Clang). A const member has the same rule (ex05, ex06, ex36).

b and c end at the inner closing brace, in reverse order: c, then b. Then d and a end at the end of main, also in reverse order: d, then a (ex14, ex15).

Question 3 of 37 L3 · Analyze construction-order In the video

Choose one: What is wrong with this constructor?

end_ comes first in the class, so it initializes first. The order of the list has no effect. So end_ reads begin_ before begin_ has a value, which is undefined behavior. The code compiles, but -Wall gives -Wreorder and -Wuninitialized warnings (ex28).

Question 4 of 37 L1 · Recall constructor

Match the terms: Match each declaration in the class Account to its name.

A constructor has the class name and no return type. The destructor adds ~ and has no parameters. The copy constructor takes a reference to the same class. = default tells the compiler to write the function.

Question 5 of 37 L1 · Recall constructor

Choose one: Which return type does a constructor have?

A constructor has no return type, not even void (ex01). It cannot return a value. A constructor that cannot make a valid object must stop with an error, for example an exception (a later episode).

After you declare a constructor, the compiler does not write a default constructor. Account a; does not compile (ex03).

Question 14 of 37 L2 · Apply member-initializer-list

Question 15 of 37 L1 · Recall default-constructor

Choose one: When does the compiler declare a default constructor for a class?

The compiler declares a default constructor only when the class declares no constructor (ex09; cppreference, Default constructors). One user-declared constructor, also a copy constructor, stops it (ex03, ex26).

Question 21 of 37 L2 · Apply destructor

Question 22 of 37 L2 · Apply destructor

C++ destroys a temporary object at the end of the full expression that makes it (ex17; [class.temporary]/4). It does not live to the end of the block.

Question 23 of 37 L3 · Analyze destructor

Select all that apply.

A destructor has no parameters, so a class has only one. It runs at the end of the scope, on every return path (ex14, ex16). C++ destroys array elements in reverse index order (ex18).

Question 24 of 37 L3 · Analyze destructor

C++ makes the array elements in index order, then z. At the end of main, C++ destroys z first, because z is the last object that it made. Then it destroys the elements in reverse index order (ex18).

Question 25 of 37 L2 · Apply copy-constructor

Question 26 of 37 L3 · Analyze copy-constructor

Question 28 of 37 L3 · Analyze copy-constructor

Question 34 of 37 L1 · Recall construction-order

Question 35 of 37 L4 · Senior construction-order

Choose one: Why does C++ initialize members in declaration order and not in the order of each member initializer list?

A class has one destructor but can have many constructors. With one fixed order, the destructor always destroys the members in the reverse order of their construction (ex30).
