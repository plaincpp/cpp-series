C++ Types and Variables: int, double, bool, char

About 12 min 52 quiz questions 62 workbook questions
Start the quiz Open the workbook Compiler Explorer (opens in a new tab)

What you learn

  • Name the fundamental types, and use sizeof and std::numeric_limits to find their size and range.
  • Explain why int and long have different sizes on different platforms, and use int32_t for a fixed size.
  • Initialize every variable, and find narrowing and uninitialized reads with the compiler and a sanitizer.
  • Predict the result of unsigned arithmetic past the limit, and explain why signed overflow is undefined behavior.
  • Compare two double values with a tolerance, and tell which type auto gets from a literal.

Question 43 of 52 L3 · Analyze floating-point

Put in order: Why does 0.1 + 0.2 == 0.3 give false? Put the steps in the correct order.

Drag the handle, or use the arrow buttons. With a row focused, press Alt + Up or Alt + Down.

  1. The two values are different, so == gives false
  2. == compares the sum with the double for 0.3, 0.29999999999999999
  3. 0.1 and 0.2 become the nearest double values, each with a small error
  4. The addition rounds the sum to the nearest double, 0.30000000000000004

Each literal and each result rounds to the nearest double. The small errors do not cancel, so the two values are different (ex24).
