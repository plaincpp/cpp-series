Part A: Concept checks

12 questions

Q1

L1 · Recall Short answer struct

What is a struct? Write a struct Book with a std::string member title and an int member pages. The value of pages must be 0 by default.

Show answerHide answer to Q1

A struct is a type that keeps related values together as data members.

The definition ends with };. The = 0 is a default member initializer, so Book b; gives pages the value 0 (ex06, ex08). std::string starts empty by itself.

Q2

L1 · Recall Short answer class

Name the only difference between struct and class in C++. The difference has two parts. Name both parts.

Show answerHide answer to Q2

The default access is the only difference (cppreference, Classes):

  1. Members: the members of a class are private by default. The members of a struct are public by default (ex20).
  2. Base classes: a class inherits privately by default. A struct inherits publicly by default (ex24).

You can write public: and private: in both. Example ex22 shows a struct and a class with the same members. They have the same behavior and the same sizeof.

Q3

L1 · Recall Multiple choice member-function

p is a Point object, and ptr is a Point* that points to p. Which two calls run the member function print on p?

  • a) print(p); and print(ptr);
  • b) p.print(); and ptr->print();
  • c) p->print(); and ptr.print();
Show answerHide answer to Q3

b) p.print(); and ptr->print();. Use . with an object and -> with a pointer (ex04, ex10). ptr->print() is the same as (*ptr).print(). Answer a) calls a non-member function print, which is a different function.

Q4

L1 · Recall Short answer access-control

Which code can use a public member of a class? Which code can use a private member?

Show answerHide answer to Q4
  • public members: all code, for example main.
  • private members: only the member functions of the class (and friends of the class, which a later episode shows).

The compiler checks the access at compile time (ex20). Source: cppreference, Access specifiers.

Q5

L1 · Recall Multiple choice this-pointer

What is the type of this in a member function of Point that is not const?

  • a) Point, a copy of the object
  • b) Point&, a reference to the object
  • c) Point*, a pointer to the object
Show answerHide answer to Q5

c) Point*. this is a pointer to the object of the call, not the object and not a reference. In a const member function, its type is const Point* (S00E11). A static_assert with std::is_same_v<decltype(this), Point*> compiles on both compilers. Source: cppreference, The this pointer.

Q6

L1 · Recall Short answer class-invariant

What is a class invariant? Give two examples of an invariant from this episode.

Show answerHide answer to Q6

A class invariant is a rule about the data members. The rule is true for each object before and after each call of a public member function. Examples from this episode:

  • The balance of an Account is never below zero (ex27, ex28).
  • The minute of a Clock is in 0-59, and the hour is in 0-23 (ex32).

Q7

L1 · Recall Short answer encapsulation

What is encapsulation? Give two advantages for the code that uses the class.

Show answerHide answer to Q7

Encapsulation puts the data in the private section and gives a small set of public member functions. All changes go through code that the class controls. Advantages:

  1. The class can keep its invariant, because no other code can change the data (ex27).
  2. The class can change how it keeps the data, and the callers do not change (ex31).

Rule C.9 of the C++ Core Guidelines tells you to keep the public part of a class small.

Q8

Q9

L2 · Apply Multiple choice member-function

Point has two int members, and sizeof(Point) is 8 on x86-64 Linux. Which change makes sizeof(Point) larger?

  • a) Add three member functions
  • b) Add a double member
  • c) Change the keyword struct to class
Show answerHide answer to Q9

b) Add a double member. The size becomes 16: 4 + 4 bytes for the int members and 8 bytes for the double. GCC and Clang print 16.

a) Member functions add no bytes, because the machine code of a function is not in the object (ex13 prints 4 8). This is true for non-virtual functions. A virtual function adds a hidden pointer to each object (S00E20). c) class changes only the default access, not the size (ex22).

Q10

L2 · Apply Multiple choice access-control

main contains the statement a.balance_ = -500;, and balance_ is a private member of Account. What happens?

  • a) The program compiles, and an exception stops it at run time.
  • b) The program compiles with a warning, and balance_ is -500.
  • c) The program does not compile.
Show answerHide answer to Q10

c) The program does not compile. GCC reports 'int Account::balance_' is private within this context. Clang reports 'balance_' is a private member of 'Account' (ex20). C++ checks access only at compile time. It never throws an exception for it.

Q11

L2 · Apply Short answer this-pointer

In a member function, what is *this? Give one reason to write return *this;.

Show answerHide answer to Q11

*this is the object of the call itself. this is its address, and * gives the object.

A function that returns *this by reference (Point&) lets you make a chain of calls on one object: p.move_by(1, 0).move_by(0, 2); (ex16). The return type must be a reference. Q17 shows the result with a copy.

Q12

L2 · Apply Multiple choice class

struct Base { int id = 7; }; has a public member. The code has class Derived : Base { }; and Derived d;. What is the result of return d.id; in main? This question is a preview: episode twenty teaches inheritance. class Derived : Base makes the class Derived from Base.

  • a) It compiles and returns 7.
  • b) It does not compile, because id is private in Derived.
  • c) It does not compile, because a class cannot inherit from a struct.
Show answerHide answer to Q12

b) It does not compile. A class inherits privately by default, so the public member id of Base is private in Derived. GCC reports 'int Base::id' is inaccessible within this context. Clang reports 'id' is a private member of 'Base' with the note constrained by implicitly private inheritance here (ex24). Write class Derived : public Base. With struct Derived : Base, the code compiles and returns 7, because a struct inherits publicly.

Part D: Explain why

9 questions

Q34

L2 · Apply Explain why struct

a and b are two Point objects with the same values. Explain why a == b does not compile (ex09). Name two ways to compare them.

Show answerHide answer to Q34

Rule: the compiler writes copy operations for a struct, but it does not write operator==. A struct can hold members that == cannot compare in a useful way, so C++ does not choose a comparison for you.

Case: GCC reports no match for 'operator==' (operand types are 'Point' and 'Point'). Clang reports invalid operands to binary expression ('Point' and 'Point') (ex09). Two ways:

  1. Compare the members: a.x == b.x && a.y == b.y.
  2. Declare bool operator==(const Point&) const = default; in the struct (C++20). Then a == b compares the members in order, and a != b also works. S00E19 teaches operators. Source: cppreference, Default comparisons.

Q35

L2 · Apply Explain why member-function

You add two member functions to Point, but sizeof(Point) stays 8 (ex13). Explain why.

Show answerHide answer to Q35

Rule: an object holds only its data members. The machine code of a member function is not in the object, and all objects of the type use the same function. This is true for non-virtual functions. A virtual function adds a hidden pointer to each object (S00E20).

Case: Point has two 4-byte int members, so its size is 8 with or without functions (ex13). Example ex33 shows that a struct with only a member function has a size of 1. That is the same size as an empty struct.

Q36

L3 · Analyze Explain why this-pointer

The objects a and b do not hold the code of Point::move_by. Explain how the same function changes a in a.move_by(5) and b in b.move_by(5).

Show answerHide answer to Q36

Rule: the compiler gives each member function a hidden argument, this, with the address of the object of the call.

Case: a.move_by(5) works like the non-member function call move_by(&a, 5), and b.move_by(5) like move_by(&b, 5) (ex11). In the body, x means this->x, so the function changes the object at the address that it gets. With g++ -O1 -fno-inline, GCC makes the same machine code for both forms: add DWORD PTR [rdi], esi and ret. In ex11 (System V x86-64 ABI), rdi holds the address of the object, because it is the register of the first argument.

Q37

L3 · Analyze Explain why access-control

Explain why private is not a security feature. What does it protect against?

Show answerHide answer to Q37

Rule: access control is a compile-time rule. The compiler refuses code that names a private member from outside the class. Nothing at run time checks it.

Case: the private data is in the same memory as public data, and the size of the class does not change (ex22). Code with a pointer to the object can read or change those bytes. A debugger or a different program can also read the memory of the process.

The keyword private protects against mistakes: a programmer cannot change the data by accident or skip the checks of the class.

Senior follow-up: access can change the size of a derived class (S00E20 teaches inheritance). On GCC and Clang (Itanium C++ ABI), a derived class can put its members in the tail padding of a base class with private data. It cannot do this with a base class that has only public data. In cpptv-toolchain:1, struct PubB : PubA { char d; }; has a size of 12, and the same struct with a private-data base has a size of 8.

Q38

L3 · Analyze Explain why class

struct Open { int balance = 0; }; accepts Open o{100};. A class with the private member balance_ gives an error for Closed c{100}; (ex23). Explain why.

Show answerHide answer to Q38

Rule: braces with values set the members directly only for an aggregate. A class with a private or protected direct data member is not an aggregate. Source: cppreference, Aggregate initialization.

Case: Open is an aggregate, so Open o{100}; sets balance to 100. std::is_aggregate_v is true for Open and false for the class. For Closed, the compiler looks for a constructor that takes one int, and there is none (ex23). This rule also protects the invariant: no code outside the class sets balance_ without a check. S00E10 adds a constructor.

Q39

L3 · Analyze Explain why class-invariant

ex26 has a struct Account with the public member balance. The rule is "the balance is never below zero". Explain why this struct cannot keep the rule.

Show answerHide answer to Q39

Rule: an invariant holds only when all changes to the data go through code that checks the rule.

Case: balance is public, so any line of the program can change it with no check. a.balance -= 500; gives -400 (ex26). The struct has no place to put the check. Make the data private, and give public functions that check each change (ex27).

Q40

L3 · Analyze Explain why encapsulation

A class Price first keeps dollars_ and cents_. You change it to one member total_cents_ (ex31). Explain why the code in main does not change.

Show answerHide answer to Q40

Rule: the callers use only the public member functions. The private members are not part of the interface.

Case: main calls only set, dollars() and cents(). The class keeps the same functions and calculates the dollars and the cents from total_cents_ (ex31). The code in main uses no private name, so it compiles and gives the same output. With public members dollars and cents, every caller must change.

Q41

L4 · Senior Explain why class-invariant

ex30 checks the invariant with assert in a private function check. Explain why assert is not a correct check for an amount that a user types.

Show answerHide answer to Q41

Rule: assert is a check for bugs in the program. The macro NDEBUG removes every assert, and release builds often define it. Source: cppreference, assert.

Case: with a failed check, ex30 stops with Assertion `balance_ >= 0' failed. and exit status 134. With -DNDEBUG, ex30 prints 70 and -430. A user can type a wrong amount in any build, so the class must refuse it with a normal check, for example return false; (ex28). Also, assert stops the whole program. That is not a correct answer to one wrong input.

Q42

L4 · Senior Explain why this-pointer

A program calls a member function through a null pointer. The function reads no data member, and the program prints the correct text on your machine. Explain why the program is still wrong.

Show answerHide answer to Q42

Rule: a member call through a null pointer is undefined behavior. The standard gives no meaning to the program, so "it works" proves nothing.

Case: on many machines, the call puts the null address in this and runs the function. A function that reads no member does not touch the address, so the output can look correct. A different compiler, flag or optimization can give a different result. GCC can also remove a later null check. With -fdelete-null-pointer-checks, GCC uses the rule that correct code never uses a null pointer.

UBSan reports runtime error: member call on null pointer of type 'Point' (ex19). Check the pointer before the call. Sources: cppreference, Undefined behavior, GCC, Optimize Options.

Part F: Design and trade-offs

5 questions

Q50

L4 · Senior Design class

Choose struct with public data or class with private data for each type below. Give the reason for each choice. Use the rules C.2 and C.8 of the C++ Core Guidelines. The types are:

  • an RGB color with three 8-bit values
  • a bank account
  • a date with a day, a month and a year
  • the options of a command-line tool
Show answerHide answer to Q50

A strong answer has these parts:

  1. The rule: the C++ Core Guidelines give two rules. Rule C.2: use class when the type has an invariant, and struct when the members can change independently. Rule C.8: use class when a member is not public.
  2. RGB color: struct. Each value in 0-255 is valid, and each can change alone. std::uint8_t already limits the range.
  3. Bank account: class. The balance has a rule, and only checked functions may change it (ex27, ex28).
  4. Date: class. The day depends on the month and the year (February 30 is not a date), so a change to one member can break the rule.
  5. Command-line options: usually struct. It is a group of independent settings. When two options must agree, the code that reads the options can check them, or the type becomes a class.
  6. Limit: the keyword alone does not keep an invariant. The private data and the checks in the member functions do.

Source: C++ Core Guidelines, C.2 and C.8.

Q51

L4 · Senior Design encapsulation

Compare three designs of Account. Design 1 has a public int balance. Design 2 has a private balance_ with get_balance() and set_balance(int), and set_balance checks nothing. Design 3 has a private balance_ with deposit, withdraw and balance(). Give one advantage and one risk of each design, and give a recommendation.

Show answerHide answer to Q51

A strong answer has these parts:

  1. Design 1, public data: simple and clear. Risk: any line can break the rule, as in ex26.
  2. Design 2, a getter and a setter with no check: it looks like encapsulation, but it is not. Any code can call set_balance(-500). Advantage: you can add a check later and the callers do not change. Rule C.131 of the C++ Core Guidelines: avoid trivial getters and setters.
  3. Design 3, behavior functions: the class gives operations of the domain. Each one checks the rule, so the invariant holds (ex28). Risk: more code, and each new operation needs a new function.
  4. Recommendation: Design 3. The names deposit and withdraw say what the caller does, and the class keeps the rule in one place.
  5. Follow-up: "When is design 1 correct?" When the type has no invariant, such as a Point.

Source: C++ Core Guidelines, C.131.

Q52

L4 · Senior Design class-invariant

A member function gets a value that breaks the invariant. Compare these four answers:

  1. Return false.
  2. Change the value to the nearest valid value (clamp).
  3. Stop with assert.
  4. Change nothing and give no report.

For each answer, give one case where it is a good choice.

Show answerHide answer to Q52

A strong answer has these parts:

  1. Return false: the caller learns about the refused change and can show a message. Good for user input, such as a withdraw that is too large (ex28). Risk: the caller can ignore the result.
  2. Clamp: the function changes the value to the nearest valid value. Good when the nearest value is a correct result for the user, such as a volume control (Q19). Risk: it hides a wrong input.
  3. assert: good for a bug in the class itself, found during tests (ex30). Risk: -DNDEBUG removes it, and it stops the whole program.
  4. No change and no report: easy (ex27), but the caller does not learn that the call failed. Use it only when a failed call has no effect that matters.
  5. Later episodes: exceptions (S00E18) and std::optional give more ways to report an error.

Q53

L4 · Senior Design member-function

You need a function distance(a, b) for two Point objects with public x and y. Compare a member function a.distance(b) with a non-member function distance(a, b). Use rule C.4 of the C++ Core Guidelines, and give a recommendation.

Show answerHide answer to Q53

A strong answer has these parts:

  1. The rule: see rule C.4 of the C++ Core Guidelines. Make a function a member only if it needs direct access to the private data of the class.
  2. Case: x and y are public, so distance does not need private access. A non-member function distance(a, b) is enough.
  3. Advantages of the non-member function: it treats both arguments the same, and the type stays small. A change to the private part of the class cannot break it.
  4. Advantages of a member: the call a.distance(b) shows the type, and an editor can list the members.
  5. Recommendation: a non-member function in the same namespace as Point. The cost is the same: a member function works like a non-member function with a hidden this argument (ex11).

Source: C++ Core Guidelines, C.4.

Q54

L4 · Senior Design encapsulation

A class keeps a private std::string name_. Compare two getters: std::string name() const (a copy) and const std::string& name() const (a reference). Talk about cost, safety and future changes to the class.

Show answerHide answer to Q54

A strong answer has these parts:

  1. Copy (std::string name() const): each call copies the string. For a long string, the copy allocates memory. It is safe, because the caller owns its copy. The class can also change how it keeps the name. For example, it can calculate the name from other members.
  2. Reference (const std::string& name() const): no copy, so it is fast. Risk: the reference is valid only while the object lives and the member does not change. A reference to the name of a temporary object becomes dangling.
  3. Future changes: a reference getter promises that the class keeps a std::string member. A copy getter does not promise this.
  4. Recommendation: a const reference for a member that the class keeps and that callers read often. A copy when the class calculates the value or when the caller keeps the value for a long time.
  5. Follow-up: "Which getter is wrong?" A reference that is not const, because it breaks encapsulation (ex29).

Q55

L3 · Analyze Interview class

What is the difference between a struct and a class in C++? When do you use each one?

Show answerHide answer to Q55

A strong answer has these parts:

  1. Main fact: the only difference is the default access. The members and base classes of a struct are public by default. Those of a class are private by default.
  2. Example: a struct with private: data and a class with the same members work the same and have the same sizeof (ex22).
  3. Use: follow the rules C.2 and C.8 of the C++ Core Guidelines. Use struct for a group of independent values. Use class when the type has an invariant or private members.
  4. Follow-ups: "Can a struct have member functions?" Yes (ex10). "Can a struct inherit?" Yes, publicly by default. A class inherits privately by default (ex24).

Source: cppreference, Classes.

Q56

L3 · Analyze Interview this-pointer

What is this? Where does its value come from, and what is its type?

Show answerHide answer to Q56

A strong answer has these parts:

  1. Main fact: this is a pointer to the object of the call. In a member function of Point, its type is Point*, and in a const member function it is const Point*.
  2. Where it comes from: the caller gives the address of the object as a hidden argument. a.move_by(5) works like move_by(&a, 5) (ex11). In ex11 (System V x86-64 ABI), the address is in rdi, the register of the first argument. The register is not a fixed rule. MSVC x64 uses rcx, and a member function that returns a large class in memory gets the return address in rdi and this in rsi.
  3. Use: x means this->x. Write this->x when a parameter hides the member (ex15). Return *this to make a chain of calls (ex16).
  4. Limits: this is a prvalue, so this = nullptr; does not compile. A call through a null pointer is undefined behavior (ex19).
  5. Follow-ups: "Do static member functions have this?" No, they have no object. "Can this be null in correct code?" No.

Source: cppreference, The this pointer.

Q57

L4 · Senior Interview struct

What is sizeof of an empty struct, and why is it not 0? How can an empty member use no bytes?

Show answerHide answer to Q57

A strong answer has these parts:

  1. Main fact: sizeof of an empty struct is at least 1. On GCC and Clang it is 1 (ex33).
  2. Why: every complete object must have its own address. Two objects in an array, or two variables, must be different. With a size of 0, they can have the same address. ex33 prints true for &a != &b.
  3. Cost: an empty member uses at least 1 byte, and alignment can add more. struct { Empty e; int x; } has a size of 8, not 4.
  4. How to save the bytes: use [[no_unique_address]] Empty e; (C++20) or an empty base class (the empty base optimization). Then the size is 4 on GCC and Clang. Containers use this for empty allocators and comparison objects.
  5. Follow-up: "Do member functions change the size?" Non-virtual member functions do not (ex13). The first virtual function adds a hidden pointer (the vptr) to each object (S00E20). On GCC and Clang, struct V { int x; virtual void f() {} }; has a size of 16, not 4.

Sources: cppreference, Empty base optimization, cppreference, no_unique_address.

Q58

L4 · Senior Interview encapsulation

A class has private data, but a getter returns int&. Is the data encapsulated? Explain the problem and the correction.

Show answerHide answer to Q58

A strong answer has these parts:

  1. Main fact: no. The data member is private, but the getter returns a reference to it. Any code can write through that reference with no check.
  2. Example: in ex29, a.balance() = -500; compiles and prints -500, although deposit refuses negative values.
  3. Correction: return a value (int balance() const) or a const reference. Give behavior functions such as deposit and withdraw for the changes.
  4. Limit: a pointer that is not const to a member has the same problem. A reference also depends on the life of the object.
  5. Follow-up: "When is a reference return correct?" For a container element access, such as std::vector::operator[]. The container has no rule about the values of its elements.

Q59

L4 · Senior Interview class-invariant

What is a class invariant? Which code must make it true, and which code must keep it true?

Show answerHide answer to Q59

A strong answer has these parts:

  1. Main fact: an invariant is a rule about the data members that is true for each object between calls. Examples: the balance is never below zero, and the minute is in 0-59.
  2. Make it true: the code that makes the object. In this episode, default member initializers do it. In S00E10, a constructor does it for a start value from the caller.
  3. Keep it true: every public member function. Each one refuses a change that breaks the rule (ex28), or corrects the values (ex32). A private function can break the rule for a short time, if the public function makes it true again before it returns.
  4. Tools: private data so that no other code can change the members, and assert to find bugs during tests (ex30).
  5. Follow-up: "Why does a struct with public data have no invariant?" Any code can change a member with no check (ex26).

Source: C++ Core Guidelines, C.2.

Q60

L4 · Senior Interview access-control

Can a member function of a class read the private members of a different object of the same class? Why does C++ allow this?

Show answerHide answer to Q60

A strong answer has these parts:

  1. Main fact: yes. Access control is per class, not per object. A member function of Account can read and write the private members of every Account object.
  2. Example: richer_than in ex25 compares balance_ with other.balance_. transfer_to in Q48 changes other.balance_.
  3. Why: the code of the class is responsible for the invariant of all its objects. Copy operations, comparisons and transfers need the data of two objects. The compiler checks access at compile time, and at compile time it knows only types, not objects.
  4. Follow-up: "Can a derived class read the private members of its base?" No. Only protected members (S00E20).

Source: cppreference, Access specifiers.

Q61

L4 · Senior Interview member-function

What does the machine do for a call of a member function such as a.move_by(5)? Compare it with a non-member function call. Does a member function make the program slower?

Show answerHide answer to Q61

A strong answer has these parts:

  1. Main fact: the machine calls a normal function. The address of the object is a hidden first argument, this.
  2. Example: ex11 compares a.move_by(5) with the non-member function call move_by(&b, 5). With g++ -O1 -fno-inline, GCC makes the same code for both: add DWORD PTR [rdi], esi and ret. In ex11 (System V x86-64 ABI), rdi holds the address of the object, and esi holds 5.
  3. Cost: the same as a non-member function call with a pointer argument. A function that you define in the class is inline (cppreference, inline specifier), so the optimizer can put its body at the call site.
  4. Limit: a virtual member function can cost an indirect call through a table. The first virtual function also adds a hidden pointer to each object (S00E20). A non-virtual member function has no extra cost.
  5. Follow-up: "Where is the code of the function?" Not in the object (ex13). All objects use the same function. The optimizer can copy the body into each call (inlining), so there can be no separate function. For ex11, GCC -O1 without -fno-inline emits no Point::move_by.

Q62

L4 · Senior Interview struct

A struct has a char, an int and a char, in that order. Its sizeof is 12 on x86-64 Linux, not 6. Explain why, and how a different order of the members changes the size.

Show answerHide answer to Q62

A strong answer has these parts:

  1. Main fact: the compiler adds padding bytes, so that each member is at an address that agrees with its alignment. On x86-64 Linux, alignof(int) is 4.
  2. Example: for char a; int i; char b;, the compiler puts 3 padding bytes after a, so that i is at offset 4. After b, it adds 3 more bytes, so that the next object in an array also starts at a correct address. That makes a size of 12. GCC and Clang print 12.
  3. Order: int i; char a; char b; puts the two char members together. The size is 4 + 1 + 1 + 2 padding bytes = 8. GCC and Clang print 8. Put the members with the largest alignment first to save memory.
  4. Trade-off: sometimes a different order is easier to read, or keeps the members that the code uses together near each other in the cache.
  5. Follow-ups: "Can you remove the padding?" Compiler extensions such as #pragma pack can do it. They are not standard C++, and an access to a member at an address with the wrong alignment can be slow. "How do you see the offsets?" offsetof from <cstddef>.

Sources: cppreference, Object (alignment), cppreference, alignof.
