Arrays, std::array and std::string

About 12 min 41 quiz questions 62 workbook questions

What you learn

  • Predict the size of a C array, and explain how an array converts to a pointer to its first element.
  • Find the sizeof mistake on an array parameter, and pass the size with a count or a std::array.
  • Use std::array and std::string to copy, compare, join and search values.
  • Compare operator[] and at(), and find an index out of range with an exception, an assertion or a sanitizer.
  • Explain why a string literal is an array of const char, and why "a" + "b" does not compile.

Question 21 of 41 L4 · Senior std-array

Choose one: On x86-64 Linux with libstdc++, why does a std::array<int, 5> use no more memory than an int[5]?

std::array holds one data member, a C array T[N]. The compiler knows N from the type, so size() needs no stored value (ex17). The standard does not promise the same size, but libstdc++ gives it. It does not compress values and has no shared table.

Question 22 of 41 L1 · Recall bounds-checking

Question 34 of 41 L4 · Senior std-string

True or false: On x86-64 Linux with libstdc++, sizeof(std::string) is 32 for an empty string and also for a string of 1000 characters.

sizeof gives the size of the object, not of its text. The object holds a pointer, a size and a small buffer, and a long text goes to the heap.

An empty libstdc++ string has capacity() 15. It keeps up to 15 characters in the object with no allocation. This is the short string optimization.

Question 35 of 41 L2 · Apply string-literal
