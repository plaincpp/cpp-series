C++ Templates: Write Code Once for Many Types

What you learn

  • Write a function template max_of and call it with int and double values.
  • Predict when template argument deduction fails, for example in std::max(3, 2.5), and correct the call.
  • Write a small Stack<T> class template and use it with the type int.
  • Explain why the compiler makes one copy of the code for each type, and why templates go in headers.
  • Find the cause of a long template error from its first error line and its "required from here" line.

Choose one: The function template is template <typename T> T max_of(T a, T b). Which call of max_of compiles?

max_of<long>(3L, 2). In the other calls, the two arguments give two types for T. With <long>, the compiler converts 2 to long (ex03, ex04).

Question 2 of 39 L2 · Apply template-instantiation In the video

Choose one: A program has these three calls. How many functions does the compiler make from max_of?

Two: max_of<int> and max_of<long>. int and long are different types. The two int calls use one function (ex16, ex35).

Question 3 of 39 L3 · Analyze templates-in-headers In the video

Choose one: The body of max_of is only in max.cpp, and the link fails. Which change corrects it?

Put the full template in the header. max.o has no max_of at all, so the link order does not help. A second declaration gives no body (ex22, ex23).

Question 4 of 39 L1 · Recall function-template

Choose one: What is a function template?

A template is not a function. The compiler makes a function from it for each type that the code uses, at compile time. A macro is text that the preprocessor copies, and it has no types.

Question 5 of 39 L2 · Apply function-template

Predict the output: What does this program print?

With <double>, the compiler does not deduce T. Then the normal conversions apply.

max_of<double>(3, 2.5) converts 3 to 3.0, and 3.0 is larger than 2.5. The cast gives the same result. max_of<int>(3, 7) gives 7.

Question 6 of 39 L3 · Analyze function-template

Choose one: v is a std::vector<int>, and the compiler is GCC or Clang on x86-64 Linux. Which call of max_of compiles?

v.size() gives std::size_t, which is unsigned long here. 0 and -1 give int, and 0u gives unsigned int. Only std::size_t{0} gives the same type for T (ex34, ex35).

Question 7 of 39 L2 · Apply function-template

True or false: In the call max_of(3, 2.5), the compiler converts 3 to double and deduces T = double.

Template argument deduction does no conversions. The first argument gives T = int, the second gives T = double, and the call does not compile (ex03).

GCC says deduced conflicting types for parameter 'T' ('int' and 'double'). Write max_of<double>(3, 2.5) or cast one argument.

Question 8 of 39 L3 · Analyze function-template

Predict the output: A normal function and a function template have the same name. What does this program print?

For the same match, the compiler prefers the normal function. Empty angle brackets select only templates.

show(3) is an exact match for both, so the normal function wins. For 2.5 and 'x', the template gives an exact match, and the normal function needs a conversion. show<>(3) selects the template.

Question 9 of 39 L3 · Analyze function-template

Choose one: The function template is template <typename T> T max_of(T a, T b). Which type does the compiler deduce for T in max_of("pear", "apple")?

A by-value parameter changes an array to a pointer, so both literals give const char* (ex05). Then < compares two addresses, not the text. Use std::string to compare the text.

Question 10 of 39 L1 · Recall class-template

Choose one: The class template is template <typename T> class Stack. Which line makes a Stack of double values?

The template argument goes in angle brackets after the name. The result Stack<double> is a type, as std::vector<double> is.

Question 11 of 39 L2 · Apply class-template

A member function outside the class needs its own template head. Write template <typename T> before line 8 (ex10). GCC says 'T' was not declared in this scope.

Question 12 of 39 L2 · Apply class-template

True or false: Stack numbers{10}; compiles, because C++17 deduces T = int from the value 10.

Class template argument deduction uses the constructors and the deduction guides. Stack has no constructor that takes a T. So the compiler cannot find T (ex33).

GCC says class template argument deduction failed. Write Stack<int> numbers;. std::vector values{1, 2, 3} compiles, because a std::vector constructor takes the values (ex12).

Question 13 of 39 L2 · Apply class-template

pop() removes 3, so the top is 2 and the size is 2. The Stack<std::string> gives the last word first, because a stack is last in, first out.

Question 14 of 39 L2 · Apply class-template

Select all that apply.

std::vector, std::pair and std::array are class templates. std::string is a type: the name of std::basic_string<char>. std::sort is a function template, and std::cout is an object.

Question 15 of 39 L1 · Recall template-parameter

Fill the blank: In a template parameter list, template <____blank T> means the same as template <class T>.

typename and class mean the same thing in a template parameter list (ex07). Many teams use typename, because T can also be int.

Question 16 of 39 L2 · Apply template-parameter

Choose one: Which line compiles?

The size of std::array is a non-type template argument, so it must be a constant expression. A normal int variable is not one. std::array<int> gives only one of the two arguments.

Question 17 of 39 L1 · Recall template-parameter

Match the terms: Match each piece of code to its name.

A type parameter takes a type. A non-type parameter takes a compile-time value. Empty angle brackets use the default for each parameter (ex15).

Question 18 of 39 L2 · Apply template-parameter

Predict the output: FixedStack<T, Capacity> keeps at most Capacity values. What does this program print?

push returns false when the stack is full. std::cout prints bool values as 1 and 0.

The first two push calls return true and the third returns false, so the size is 2. The capacity is part of the type, so FixedStack<int, 2> and FixedStack<int, 3> are different types.

Question 19 of 39 L2 · Apply template-parameter

True or false: FixedStack<int, 2> and FixedStack<int, 3> are the same type, because both keep int values.

Each template argument is part of the type, also a non-type argument. std::is_same_v<FixedStack<int, 2>, FixedStack<int, 3>> is false (ex13).

A function for stacks of all sizes must be a template on Capacity too.

Question 20 of 39 L3 · Analyze template-instantiation

Predict the output: What does this program print?

Each instantiation is a different function with its own static variable.

count_calls<int> runs two times, so its counter gives 1, then 2. count_calls<double> and count_calls<char> each have their own counter, so each gives 1.

Question 21 of 39 L2 · Apply template-instantiation

Choose one: Which two calls use the same function that the compiler makes from max_of?

max_of(1, 2) deduces T = int, and <int> gives the same T. So both calls use max_of<int>. One static counter counts both calls (ex35). long, float and char are different types, so each gives a different function.

Question 22 of 39 L3 · Analyze template-instantiation

True or false: The compiler makes every member function of Box<Point>, also a member function that the code never calls.

The compiler makes a member function of a class template only when the code uses it. Box<Point> compiles until the code calls print() (ex19, ex20).

This rule lets you use a class template with a type that has only some of the operations.

Question 23 of 39 L3 · Analyze template-instantiation

Put in order: Put the steps in order for the call max_of(3, 7).

Drag the handle, or use the arrow buttons. With a row focused, press Alt + Up or Alt + Down.

  1. The compiler finds the call max_of(3, 7)
  2. The program calls max_of<int> when it runs
  3. The compiler makes max_of<int> and checks a < b for int
  4. The compiler deduces T = int from the two arguments
  5. The compiler reads the template and checks the names that do not depend on T

Two-phase lookup: the compiler checks the names that do not depend on T at the definition (ex21). It checks the names that depend on T, such as a < b, at the instantiation.

Select all that apply.

Each instantiation is a new type with its own members and its own functions (ex17). The types are not related, so Stack<double> prices = whole; does not compile (ex18).

Question 25 of 39 L4 · Senior template-instantiation

Choose all that apply: A header-only template library makes the build slow and the program large. Which changes help? Select all correct answers.

Select all that apply.

Each template argument makes more machine code and more compile time. An extern template line stops the instantiation in each translation unit (cppreference: explicit instantiation). #pragma once and inline do not change the number of instantiations.

Question 26 of 39 L1 · Recall templates-in-headers

Choose one: Where do you usually put the full definition of a function template?

The compiler must see the full definition to make max_of<int>. So the template goes in a header, and each translation unit that calls it includes the header (ex23).

Question 27 of 39 L3 · Analyze templates-in-headers

Choose one: The template body is in max.cpp. max.h has only the declaration. main.cpp includes max.h and calls max_of(3, 7). What happens?

max.cpp calls nothing, so it makes no max_of code. main.cpp needs max_of<int>, but it sees no body. The linker says undefined reference to `int max_of<int>(int, int)' (ex22).

Question 28 of 39 L3 · Analyze templates-in-headers

Fill the blank: To make max_of<int> in max.o, write the explicit instantiation ____blank int max_of<int>(int, int); in max.cpp.

An explicit instantiation tells the compiler to make the function for this type in this file (ex24). The header then declares it with extern template.

Question 29 of 39 L3 · Analyze templates-in-headers

True or false: Two .cpp files that include one template definition from a header break the one-definition rule, so the link fails.

The one-definition rule allows one definition of a template in each translation unit, if all the definitions are the same (cppreference: definitions and ODR).

nm shows W int max_of<int>(int, int) in both object files. W is a weak symbol, and the linker keeps one copy (ex23).

Question 30 of 39 L2 · Apply templates-in-headers

Match the terms: Match each nm -C result or linker message to its meaning.

nm prints U for an undefined symbol and W for a weak symbol (GNU binutils: nm). A template body without a call or an explicit instantiation makes no symbol (ex22, ex23).

Question 31 of 39 L4 · Senior templates-in-headers

Choose one: A library ships as a compiled file, and its template must work only for int and double. The users must not see the body. Which design fits?

Explicit instantiations make the two functions in the library (ex24). The header declares the template and the extern template lines. A call with another type gives an undefined reference, so document the two types.

Question 32 of 39 L2 · Apply template-errors

The first error: line gives the cause, for example no match for 'operator-'. Then find the required from here line in your own file. The lines after the first error often follow from it.

Question 34 of 39 L3 · Analyze template-errors

Choose all that apply: max_of(Point{1, 2}, Point{3, 4}) gives no match for 'operator<' (operand types are 'Point' and 'Point'). Which changes make the call compile? Select all correct answers.

The template needs a < b for Point. A member operator<, a free operator< and a default operator<=> all give it. A default operator<=> needs #include <compare>. max_of<int> fails, because a Point does not convert to int.

Question 35 of 39 L2 · Apply template-errors

Clang writes requested here where GCC writes required from here. The line names your call, std::sort on a std::list (ex26). The first error: line gives the cause, and this line gives the place in your code.

Question 36 of 39 L4 · Senior template-errors

Choose one: A team writes template <std::totally_ordered T> for max_of. What changes in the GCC error for max_of(Point{1, 2}, Point{3, 4})?

The constraint puts the first error at the call (ex28). A note under it says constraints not satisfied. On GCC the full message is longer: 31 lines, against 7 lines without the constraint (ex25). The gain is the place and the name of the requirement, not the length.

Both parameters use T. So the types of the two arguments must agree, or deduction fails.

Question 38 of 39 L4 · Senior class-template

Choose one: Must Stack<T>::top() check for an empty stack? Which statement gives the main trade-off?

std::vector::back() on an empty vector is undefined behavior, so the Stack template adds no safety (ex32). The standard containers leave this precondition to the caller for speed. A checked top() can throw an exception or use assert.

Question 39 of 39 L4 · Senior template-parameter

Choose one: The users of your stack choose its capacity when the program runs. Which design fits?

A non-type template argument must be a constant expression, so a run-time value cannot be Capacity (ex14). A const int that gets its value from the input is not a constant expression either. The FixedStack design gives a fixed size with no heap allocation, but each capacity is a different type. For a run-time size, use std::vector.
