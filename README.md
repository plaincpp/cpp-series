# Plain C++

C++ from zero to senior. One concept at a time.

- Videos: https://www.youtube.com/@plaincpp
- Quizzes and workbooks: https://plaincpp.github.io/cpp-series/

## Code examples

Each episode has a folder `episodes/<ID>-<name>/examples/`. Each example is a `.cpp` file. The `.expected` file next to it shows the output. Every example compiles on GCC 14 and Clang 19 with `-std=c++23 -Wall -Wextra -Wpedantic`.

Some examples do not compile, or show undefined behavior, on purpose. The first lines of the file tell you the expected result.
