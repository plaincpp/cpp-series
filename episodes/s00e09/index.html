Structs and Classes: Data and Behavior Together

About 12 min 37 quiz questions 62 workbook questions
Start the quiz Open the workbook Compiler Explorer (opens in a new tab)

What you learn

  • Use a struct to keep related data together, and give each member a default value.
  • Write member functions, and explain how the hidden this pointer gives each call its object.
  • Use private data and public member functions to keep a class invariant true.
  • Explain the only difference between struct and class, and find the errors that access control gives.

Question 14 of 37 L1 · Recall class

True or false: The members of a struct are private by default.

The members of a struct are public by default. The members of a class are private by default.

This default is the only difference between struct and class (cppreference, Classes). ex22 shows a struct and a class that work the same.

Question 21 of 37 L3 · Analyze access-control

Choose one: When does C++ check that code does not use a private member?

Access control is a compile-time rule. It adds no instructions, and it does not change the size of the class: ex22 shows the same sizeof for a struct and a class. It is not a security feature.

Question 22 of 37 L2 · Apply encapsulation

True or false: The member balance_ is private, so the getter int& balance() { return balance_; } keeps the balance safe from code outside the class.

The getter returns a reference to the private member. Any code can write through it: a.balance() = -500; compiles (ex29).

Return a copy (int balance() const) or a const reference. Then only the member functions can change the data.

Question 32 of 37 L2 · Apply this-pointer

Put in order: Put the steps of the call a.move_by(5) in order. move_by does x += dx;.

Drag the handle, or use the arrow buttons. With a row focused, press Alt + Up or Alt + Down.

  1. The body reads the value at this->x
  2. The body writes that value plus 5 to this->x
  3. The function returns, and a.x is 5 larger
  4. main calls move_by and gives it the address of a as this

A member call works like a non-member function call with a hidden first argument. In ex11, a.move_by(5) and move_by(&a, 5) give the same result. With -O1 -fno-inline, GCC makes the same machine code for both.

Question 37 of 37 L4 · Senior class

Choose one: The C++ Core Guidelines say: use class when the type has an invariant. Which type is the best choice for class with private data?

The day of a date depends on the month and the year, so a change to one member can break the rule. Each member of a point or of an 8-bit color can change alone, and every value is valid. Rule C.2 of the guidelines uses struct for those types.
