What you learn

  • Write a first program that writes text, then compile it and run it on your computer or in Compiler Explorer.
  • Compare std::cout, std::print and printf, and tell when std::endl is necessary.
  • Explain how the return value of main becomes the exit status of the program.
  • Use the flags -std=c++23 -Wall -Wextra -Wpedantic and find bugs from the warnings.
  • Find the cause of a failed build in the first error message.

Question 13 of 44 L1 · Recall iostream

Question 14 of 44 L2 · Apply iostream

True or false: '\n' and std::endl do the same work.

The two write the same new line. But std::endl also flushes the stream: it sends the text in the buffer out now.

Example ex04 writes the same three lines with the two forms. The difference is the flush, and you see it only in the speed or after a crash.

Question 15 of 44 L3 · Analyze iostream

Choose one: You run this program with ./app > out.txt. What does out.txt contain after the crash?

std::endl flushes step 1 to the file. The library collects output to a file in a full buffer, so step 2 stays in the buffer. On Linux (glibc), std::abort stops the program without a flush.

Question 16 of 44 L3 · Analyze iostream

Select all that apply.

std::cerr writes to the standard error stream, and > sends only standard output to the file. It flushes after each output operation, so a crash does not lose its text.

Question 18 of 44 L4 · Senior iostream

Question 22 of 44 L2 · Apply compiler-flags

Drag the handle, or use the arrow buttons. With a row focused, press Alt + Up or Alt + Down.

  1. Write the code in main.cpp
  2. Run the program with ./app
  3. Read the exit status with echo $?
  4. Compile with g++ -std=c++23 -Wall -Wextra -Wpedantic main.cpp -o app

The flags come on each build. Correct the messages before you run the program, because a warning can show undefined behavior.

Question 23 of 44 L4 · Senior compiler-flags

Choose one: Why does a team put -std=c++23 in its build file, and not use the default standard of the compiler?

The default is different between compilers and versions: GCC 14 uses gnu++17, GCC 10 used gnu++14, and MSVC uses C++14. A fixed -std gives the same language on each computer.

Question 24 of 44 L2 · Apply compiler-warnings

True or false: -Wall turns on all the warnings of GCC.

-Wall turns on a large set of common warnings, not all. For example, with -Wall, -Wextra adds -Wunused-parameter. Neither flag turns on -Wshadow.

Use -Wall -Wextra -Wpedantic on each build. Add other warnings, such as -Wshadow, when your team needs them.

Question 25 of 44 L3 · Analyze compiler-warnings

Select all that apply.

GCC puts -Wunused-variable, -Wsign-compare and -Wuninitialized in -Wall. An unused parameter needs -Wextra, and a hidden variable needs -Wshadow.

Question 26 of 44 L3 · Analyze compiler-warnings

Question 30 of 44 L2 · Apply compiler-warnings

Question 32 of 44 L1 · Recall exit-status

For main only, the end of the function has the same effect as return 0;.

Example ex01 has no return, and echo $? prints 0. This rule is for main only. For other functions that return a value, the same mistake is undefined behavior.

Question 33 of 44 L3 · Analyze exit-status

Choose one: On Linux, main returns 256. What does echo $? print?

The shell gets only the low 8 bits of the value. 256 is 1 0000 0000 in binary, so the low 8 bits give 0. Thus a count of errors can report success by mistake.

Question 36 of 44 L2 · Apply exit-status

Match the terms: ./app writes nothing and returns 1. Match each bash command to its result.

The operator && runs the next command only after status 0. The operator || runs it only after another status. The ; runs it after any status.

Question 37 of 44 L4 · Senior exit-status

Choose one: A build script runs ./tests | tee log.txt in bash. The tests fail and return 1. What is $? after the pipeline, with the default options?

The status of a pipeline is the status of its last command, here tee. Thus the build server sees success. Use set -o pipefail, and then $? is 1.

Question 39 of 44 L3 · Analyze compiler-explorer

Question 40 of 44 L3 · Analyze compiler-explorer

Choose one: In Compiler Explorer, you build ex18 with -O2. The assembly of main has no call to square. Why?

At -O2, GCC puts the body of square into main and calculates 7 * 7. In g++ -S output (AT&T syntax), main loads 49 with movl $49, %esi. The website shows the same code in Intel syntax by default: mov esi, 49. At -O0, main calls square.
