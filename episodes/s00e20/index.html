Inheritance and Virtual Functions: The Basics

About 12 min 39 quiz questions 62 workbook questions
Start the quiz Open the workbook Compiler Explorer (opens in a new tab)

What you learn

  • Write a derived class with public inheritance, and predict the order of its constructors and destructors.
  • Predict which function a call through a base pointer or a base reference runs, with virtual and without it.
  • Use override to make the compiler find a function that does not override, for example because of a missing const.
  • Use a pure virtual function to make an interface, and explain why Shape shape; does not compile.
  • Explain why a base class with virtual functions needs a virtual destructor, and find the bug with AddressSanitizer.

Question 17 of 39 L4 · Senior virtual-function

Choose one: The standard does not tell how to make a virtual call. How do GCC and Clang usually do it?

Each object of a class with virtual functions has a hidden pointer (vptr) to a table of function addresses (vtable). The Itanium C++ ABI, which GCC and Clang use on Linux, defines this layout. A switch cannot know types that you add later, and no name search occurs.

Question 18 of 39 L3 · Analyze virtual-function

Choose one: On x86-64 Linux, struct Plain { int id; }; has sizeof 4. When you add one virtual function, sizeof is 16. Why is it 16 and not 12?

The vptr is 8 bytes and the int is 4 bytes. The size of the object must divide by 8 with no remainder, so it is 16 (ex20). The count of virtual functions changes the vtable, not the object.

Question 24 of 39 L1 · Recall pure-virtual

= 0 makes a virtual function pure (ex15). = default is for special member functions and comparison operators, and = delete removes a function. C++ has no abstract keyword, unlike Java and C#.

Question 32 of 39 L4 · Senior runtime-polymorphism

A template makes one function for each type at compile time, so the compiler can inline each call. A choice from input at run time (ex27) and a container of mixed types (ex26) usually use virtual functions. Another tool is std::variant, in a later season.

Question 38 of 39 L4 · Senior virtual-function

Put in order: shape is a Shape*, and draw is virtual. Put the steps of shape->draw() in order, as GCC and Clang usually do them.

Drag the handle, or use the arrow buttons. With a row focused, press Alt + Up or Alt + Down.

  1. Call that address with shape as this
  2. Go to the vtable of the dynamic type
  3. Read the address of draw from its slot in the vtable
  4. Read the vptr from the object at the address in shape

The constructor of each class sets the vptr (Itanium C++ ABI). A virtual call needs two memory reads and one indirect call, and the compiler usually cannot inline it. A non-virtual call is one direct call.

Question 39 of 39 L4 · Senior pure-virtual

Choose one: A pure virtual function can have a body outside the class. Why do you give it one?

An override calls the body with a qualified name, such as Shape::describe(). The class stays abstract (cppreference: abstract class). A pure virtual destructor must have a body, because every derived destructor calls it (ex25).
