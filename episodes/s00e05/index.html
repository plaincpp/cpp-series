Control Flow in C++: if, switch and Loops

About 12 min 42 quiz questions 61 workbook questions
Start the quiz Open the workbook Compiler Explorer (opens in a new tab)

What you learn

  • Use if and else to select one branch, and use an if initializer to limit the scope of a variable.
  • Predict the output of a switch statement, and use break, default and [[fallthrough]] correctly.
  • Compare the for, while and do-while loops, and select the correct loop for a task.
  • Use a range-for loop to visit each element of an array, and use break and continue to control a loop.
  • Find an off-by-one loop bound, a missing break and an empty if body with compiler warnings and sanitizers.

Question 14 of 42 L4 · Senior switch-statement

Choose one: ex22 has a switch with the case values 0 to 5 and a default. Each case prints a different string. What does GCC make from it with -O2 on x86-64?

Question 15 of 42 L2 · Apply switch-statement

True or false: The default label must be the last label in a switch.

False. The default label can be at any position. Most code puts default last because it is easy to read. A default at the top also needs a break, or it falls through. Source: cppreference, switch statement.

Question 16 of 42 L2 · Apply for-loop

Drag the handle, or use the arrow buttons. With a row focused, press Alt + Up or Alt + Down.

  1. Run the increment ++i
  2. Run the init statement int i = 0 one time
  3. Test the condition i < 2 again
  4. Test the condition i < 2

The init statement runs one time. Then the loop tests the condition before each step and runs the increment after each step (ex23).
